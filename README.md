# Przepisz to

Repo to store literature rewritten with AI in different styles.

Klasyka literatury przepisana z pomocą AI w stylu współczesnych autorów — ta sama historia, inny głos. Teksty są publikowane jako strony HTML przez GitHub Pages i podlinkowane z Instagrama „Przepisz to”.

## Struktura

- `index.html` — strona główna
- `lalka/` — „Lalka” Bolesława Prusa w stylu Sapkowskiego, Lipińskiej i Żulczyka
- `assets/` — logo i wspólne grafiki

Wszystkie teksty to pastisze pisane dla zabawy. Oryginały w domenie publicznej: [Wolne Lektury](https://wolnelektury.pl).
